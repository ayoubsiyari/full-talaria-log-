Download dataset (FirstRate Data)

Pick an instrument type, a period, a timeframe, and optionally the tickers you want — then hit Download & import now. Each matching symbol in the vendor ZIP becomes a dataset you can chart. Requires FIrstrate_USERID on the server.

For period=full, FirstRate splits stock / ETF / options into one ZIP per letter. Leave on auto and list your tickers below — the server downloads every needed letter automatically (e.g. AAPL, TSLA → letters A + T). With no tickers listed, auto sweeps the full A–Z (slow). Pick a single letter only to restrict manually. Futures use continuous-contract bundles instead of letter shards (select the adjustment below).

Duplicate symbols are merged automatically when you Download & import or Save schedule (same rules as the server filter).

FirstRate duplicate datasets
not scanned

Groups FirstRate-imported datasets that share the same canonical ticker (e.g. an old EURUSD_full_1min_1min.csv seed and a newer EURUSD_1min.csv from a daily nightly run). For each group you pick the winner — typically the row with the most bars, which is the historical seed — and the smaller "loser" rows get their bars merged into the winner before being moved to uploads/_quarantine/. The big dataset is never deleted: it's the winner. Losers are quarantined, not erased, so a manual restore is always possible.

How the merge works: the loser's bars are added to the winner by timestamp. If a bar at the same minute exists in both, only one copy survives (the loser's value wins ties — it's the freshest vendor print). Total bars after the merge can only stay the same or grow — never decrease. The big winner CSV is preserved on disk; only the small loser rows are moved to uploads/_quarantine/. The confirmation phrase below is auto-filled from the server's DATASET_PURGE_CONFIRMATION env var when you scan.

No FirstRate duplicate groups found — every canonical ticker maps to exactly one row.

Rate limit: 5 sends per minute.
