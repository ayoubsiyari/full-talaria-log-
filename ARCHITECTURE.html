🔄Key Data Flows

🔐 Authentication Flow
User → Browser → Login form (journal-frontend or homepage)
POST /api/auth/login → Flask journal-backend validates credentials
JWT Issued → Stored in AuthContext (localStorage)
Bearer Token → All API calls via Authorization header
ProtectedRoute → Checks AuthContext, redirects if unauthenticated
📥 Trade Import Flow
ImportTrades.jsx → CSV file upload or FTP pull (NinjaTrader, etc.)
PapaParse → Client-side CSV parsing & validation
POST /import → journal-backend import_export.py
ImportBatch → Batch record + JournalEntry rows saved to PostgreSQL
FTP (Live) → Profile.ftp_* credentials for live mode auto-sync
💳 Subscription Flow
Pricing.jsx → User selects plan (Individual / Group)
POST /create-checkout → Flask creates Stripe session
Stripe Checkout → Hosted Stripe payment page
Webhook → POST /webhook → updates User.access_expires_at
SubscriptionGuard → Frontend gating of premium features
📊 Analytics Computation Flow
Analytics pages → User navigates to analytics sub-page
GET /analytics → Flask aggregates trade data from PostgreSQL
metrics.js → Client-side metric calculations (10 KB)
Recharts → Chart rendering (Equity, PnL, Distributions…)
FilterContext → Global filter state applied across all analytics views

🛡Auth & Access Control Architecture

🔑 User Roles
  • admin Full platform access, admin routes, bulk email, user management
  • user (group) Group-level feature flags, shared group variables
  • user (individual) Personal profiles, subscription-gated features
🚦 Feature Flags System
  • GroupFeatureFlags Per-feature, per-group toggle in DB
  • FeatureFlagsContext React context distributes flags to components
  • FeatureDisabled.jsx Fallback UI for disabled features
  • GroupFeatureFlagManager Admin UI to toggle per-group
  • GET /api/feature-flags Fetched on login / profile switch
💰 Subscription Gating
  • SubscriptionGuard HOC wrapping premium routes
  • SubscriptionRequired.jsx Paywall landing page
  • subscription_access.py Backend plan-level checks
  • User.access_expires_at Expiry date from Stripe webhooks
  • User.has_journal_access Manual override flag
