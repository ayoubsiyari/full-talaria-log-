Zone J — Metrics & Scaling Strategy
Frontend-vs-backend is the wrong axis. What scales is where the cost lands + whether it's cached. Frontend calc is server-cheap but ships raw trades & lags weak devices; backend calc is authoritative but centralizes CPU — only scales with caching + compute-on-write. Use a hybrid. See the Metrics tab.
⚖️ hybrid split
heavy → backend · light → client Authoritative vs interactive
🗄 DB-side aggregation
SQL GROUP BY · QuestDB SAMPLE BY Cheapest place to crunch
⚡ Redis cache
key: user·profile·filters·version COMPUTE ONCE Biggest scalability lever
✍️ compute on write
update aggregates on trade write NOT ON READ Reads become cheap lookups
⚙️ offload to worker
trading-chart-worker · rate limits Keep API handlers responsive
